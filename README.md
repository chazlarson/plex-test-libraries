# plex-test-libraries
Some pre-made test libraries for Kometa or whatever

Clone the repo somewhere, point your media server at it.

Beware, there are some very long filenames here that git on the command line in Windows doesn't like by default.

This stackoverflow post has sopme details and some possible workarounds:

https://stackoverflow.com/a/22575737

The author has no Windows machines, so this is not an issue for him.

These were created initially by: https://github.com/chazlarson/test-lib-maker

If you want different movies/shows and can run a shell script, look into it.
